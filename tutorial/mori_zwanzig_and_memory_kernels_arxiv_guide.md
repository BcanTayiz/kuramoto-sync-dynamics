# Open-Access arXiv Resources: Mori-Zwanzig Formalism & Memory Kernels

## 1. Best Starting Point for Beginners & Derivations
* **[Partial Observation of Linear Systems with the Mori-Zwanzig Formalism](https://arxiv.org/html/2606.23341v2)** (`arXiv:2606.23341`)
  * **Overview:** Builds the mathematics from the ground up using concrete, solvable examples (such as a simple harmonic oscillator and the 2D wave equation). Explicitly demonstrates how a clean, memoryless system splits into three distinct parts when variables are hidden: a Markovian term, a noise term, and a Volterra memory kernel.

## 2. Self-Contained Review & Machine Learning Bridge
* **[Data-Driven Learning for the Mori–Zwanzig Formalism](https://arxiv.org/html/2101.05873v3)** (`arXiv:2101.05873`)
  * **Overview:** Section 3 provides a comprehensive, self-contained tutorial on the Mori-Zwanzig formalism, including two full mathematical derivations of the Generalized Langevin Equation (such as the operator-algebraic Dyson identity derivation) and an explanation of the Generalized Fluctuation-Dissipation Theorem. The remainder of the paper demonstrates how to learn these memory kernels from data.

## 3. Rigorous Functional Analysis of Memory Integrals
* **[On the Estimation of the Mori-Zwanzig Memory Integral](https://arxiv.org/pdf/1708.02235)** (`arXiv:1708.02235`)
  * **Overview:** Focuses on the functional analysis behind projection operators ($P$ and $Q$) and Hilbert spaces in Sections 2 and 3, proving mathematical bounds on whether memory integrals decay or blow up over time.

## 4. Modern Neural Operators & Generative Memory Kernels
* **[Physics-Informed Traditional and Generative Mori-Zwanzig–Reduced Models](https://arxiv.org/html/2611.05211v1)** (`arXiv:2611.05211`)
  * **Overview:** Connects classical projection-based memory kernels directly to modern physics-informed machine learning and neural networks, complete with explicit integral equations and numerical discretization plots.
* **[Is Memory All You Need? Data-Driven Mori-Zwanzig Modeling](https://arxiv.org/html/2507.16058v1)** (`arXiv:2507.16058`)
  * **Overview:** Demonstrates how neural networks parameterize autoregressive memory kernels to maintain long-term stability in complex, turbulent non-equilibrium systems.
