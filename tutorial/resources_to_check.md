# Recommended Literature: Non-Markovian Dynamics, Memory Kernels, and Thermodynamic Consistency in Neural Operators

## 1. Learning Memory Kernels with Neural Networks
* **Learning Memory Operators with Physics-Informed Neural Networks** (*Mathematics*, 2026)
  * **Summary:** Tackles how to discover hidden memory effects from data using a Prony series (sum of decaying exponentials), guaranteeing that memory fades naturally without violating basic physical rules.
* **Fractional Physics-Informed Neural Networks for Surrogate Modeling** (*PMC*, 2026)
  * **Summary:** Explores how Caputo fractional derivatives capture temporal memory in noisy environments like non-Markovian random walks.

## 2. Enforcing Thermodynamic Consistency in Neural Operators
* **GENERIC-FNO: Embedding Energy Conservation and Entropy Production into Neural Operators** (*arXiv*, 2026)
  * **Summary:** Introduces a neural operator built around the GENERIC formalism, baking energy conservation and non-negative entropy production directly into the architecture.
* **Neural Operators for Non-equilibrium Dynamics of Mott Insulators** (*arXiv*, 2026)
  * **Summary:** Demonstrates how neural operators simulate complex, strongly correlated materials driven far from equilibrium, bridging microscopic simulations and large-scale thermodynamic behavior.

## 3. Fractional Derivatives in Operator Learning
* **Fractional is Better: Learnable Derivative Orders in Neural Operators** (*OpenReview*, 2026)
  * **Summary:** Shows that allowing a neural operator to learn continuous, fractional-order derivatives improves performance on noisy, finite data by balancing fine physical details against noise amplification.

## 4. Theoretical Physics Foundations (The H-Theorem & Memory)
* **Generalized Kinetic Equations with Fractional Time-Derivative and Non-Singular Kernels** (*PMC*, 2024)
  * **Summary:** Connects fractional diffusion equations and memory kernels directly to the H-theorem (the Second Law of Thermodynamics) and generalized entropy forms.
